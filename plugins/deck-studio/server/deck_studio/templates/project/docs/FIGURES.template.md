# FIGURES: as figuras da fonte que o deck usa

Copie para `docs/FIGURES.md` e preencha na fase B. Cada linha é uma figura que vai para o deck. `qa/check_deck.py`
confere se o **Rótulo** de cada linha aparece na legenda (`figcaption.cap`) de algum slide e se toda imagem tem alt e
carregou. Uma figura que não vai para o deck não entra aqui; diga no resumo por que ficou de fora.
