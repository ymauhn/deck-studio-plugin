Data: a CAFA5-derived corpus

  • 80 / 10 / 10 split, disjoint at protein level, no temporal or homology constraint
  • Labels per protein (mean): 25.91 BP, 12.48 CC, 7.55 MF
  • Label matrix density: BP5.18% CC2.51% MF1.51%

The official CAFA5 test labels were not available, so the splits come from the training corpus.

Only about five hundred most frequent terms per ontology are kept, which makes absolute values not comparable with CAFA numbers.

STRING v11.5: one aggregated network

  • 2,422,234 records, 791,011 distinct pairs, 86,423 proteins
  • Combined score in [0.400, 0.999]; confidence, not binding strength
  • Each pair repeated 3.06 times on average (up to 170), always with the same score
  • Degree is heavy-tailed: median 5 to 7, maximum 763 to 805

The medium-confidence floor of 400 comes with the inherited file.

Repeated records carry no extra score information, which later decides the deduplication rule. Some knowledge circularity with the annotations cannot be excluded.

One third of the proteins have no edge

  • Isolated: 36.65% BP, 34.95% CC, 32.19% MF
  • Stable across training, validation and test
  • Thresholds up to 0.40 are inert; at 0.90 more than half the proteins are isolated

Isolated proteins were kept as nodes so that every protein is scored. For a model that sees only the network, these proteins have no input at all.

This is the limitation the second generation is built to remove.

Six protein-centric metrics

  • Primary criterion: wFmax, information-content weighted
  • Also Fmax, F*max, Smin, AuPRC, IAuPRC
  • Predictions made hierarchy-consistent before scoring
  • 101 thresholds; full evaluation mode (unpredicted proteins count as zero recall)
wF_{\max} = \max_{\tau}\, \frac{2 \cdot wpr(\tau) \cdot wrc(\tau)}{wpr(\tau) + wrc(\tau)}

each term weighted by its information content, \mathrm{IC}(v) = -\log_2 \widehat{P}\bigl(v \mid \mathrm{pa}(v)\bigr)

\tilde{s}_{iv} = \max_{u \in \mathcal{D}(v)} s_{iu}

wFmax weights each term by information content, so frequent terms near the root count little. It is the selection criterion everywhere.

The ancestor closure of predictions uses is_a only, which matters most for CC.

Learning regime and protocol

  • One graph over train ∪ validation ∪ test; labels read only for training proteins
  • Every design decision on validation; test read once
  • Single seed: differences below 0.5 pp are ties (interpretability floor)

Validation and test proteins contribute features and edges but never labels. The first generation uses a stricter train-basis construction.

With a single seed, the talk treats sub-0.5 pp gaps as ties.
