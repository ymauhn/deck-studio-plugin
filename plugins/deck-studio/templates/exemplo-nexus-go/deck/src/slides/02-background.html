Graphs, adjacency and message passing

  • G = (V, E, w): proteins, associations, STRING confidence
  • Message passing: aggregate neighbours, update the node
  • Adjacency matrix A; sparse storage O(|E|)
  • L layers reach L hops; too many cause oversmoothing

GCN aggregates with a symmetrically normalized adjacency; GAT learns attention weights over neighbours.

Each layer widens the receptive field by one hop, and too many layers make neighbouring representations indistinguishable.

Protein language models

  • Self-supervised pretraining on hundreds of millions of sequences
  • Transformer encoder: every residue attends to every other
  • ProtT5-XL-U50: T5 encoder, BFD then UniRef50, 15% residue masking
  • Used here as a frozen feature extractor

Language models turn function prediction into ordinary multi-label classification over a fixed-length vector.

No gradient from our task reaches ProtT5; we read three encoder layers and keep them fixed.

From neighbour voting to graph transformers

The field moved from fixed diffusion to learned attention, and each step added parameters.

Decoupled methods such as SGC and APPNP move against that trend, and SEGT-GO's multi-hop aggregation is itself a plain matrix product.

The open question

Is a learned graph component still needed once the propagated object is informative?

  • Proposal: propagate ProtT5 embeddings with a fixed, finite-step operator, then use an ordinary head
  • A sequence representation exists for every protein, so the network adds instead of supplies
  • No prior visual route starts from a propagated language-model embedding

The contribution is an architectural placement, not a new propagation mechanism.

To our knowledge no previous work propagates protein language model embeddings directly while simplifying what consumes them.
